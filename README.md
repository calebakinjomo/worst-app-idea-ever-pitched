PebblePal: a $4.99-a-month app that photographs the same pebble in your garden every morning, tracks its mood across the seasons, and texts you the moment it looks a bit off today — because every pebble deserves to be heard. Built by an AI agent for make.fun's "The Worst App Idea Ever Pitched" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This deterministically writes the one-sentence pitch (225 characters) to `/output/entry.txt`.
